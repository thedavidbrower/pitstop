# Pitstop

A Trello-style car maintenance tracker for multiple vehicles. One static HTML file, no build step, no backend.

## Features
- One tab per vehicle, with a mileage odometer
- Kanban board: Planned, Due soon, In the shop, Done (drag cards between columns)
- Tasks with due date, due-at mileage, cost, notes and receipt photos
- Overdue tasks are flagged
- Data stays in your browser (localStorage for tasks, IndexedDB for receipt photos)

## Run it
Open `index.html` in a browser.

## Host it free
Repo Settings > Pages > deploy from the `main` branch, root folder.
